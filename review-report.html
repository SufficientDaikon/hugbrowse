Findings by Severity

🔴 Critical (4)

C-1: RAG pipeline not implemented

FR-035/036/037 — No chunking, embedding, or retrieval logic. rag.ts is a stub store only. SC-009 (RAG query referencing PDF) cannot be achieved.

C-2: MCP tool-call dispatch not wired into chat

FR-041 — mcp-client.ts callTool() exists but chat.ts sendMessage() never detects tool-call JSON blocks from model output or dispatches them. MCP is decoration-only.

C-3: System tray entirely missing

FR-045/046 — No tray plugin, no tray code. Model keeps running but app closes fully. Blocks key UX expectation for desktop AI apps.

C-4: EC-004 get_downloads uses wrong enum variants

download.rs:495-499 references DownloadStatus::Completed and DownloadStatus::Error which don't exist in the enum (should be Complete and Failed). This will cause a compile error.

🟠 Major (7)

M-1: No tokens/second or context usage display (FR-027)

Chat interface doesn't calculate or display generation speed metrics. Users have no visibility into model performance.

M-2: No custom API server layer (FR-031/032)

Relies on llama-server's built-in endpoints. No HTTP 503 when no model loaded, no auto-start on launch.

M-3: No sidecar binary checksum (FR-020, EC-003)

llama-server binary never verified. Truncated or corrupted binary causes cryptic spawn errors.

M-4: Health polling too slow for NFR-009

spawn_health_poller polls every 10s, requires 3 failures (~30s). Spec requires detection within 2 seconds.

M-5: No auto-update UI (FR-047/048)

tauri-plugin-updater registered in Rust, no frontend checks or notifications. Users won't know about new versions.

M-6: Multi-GPU not supported (EC-007)

detect_gpu returns only first GPU. No enumeration or selection for workstation/server users.

M-7: Tool Call badge missing (FR-043)

No visual indicator in chat when MCP tool calls are in flight.

🟡 Minor (6)

m-1: System prompt UI not visible (FR-026)

setSystemPrompt exists in store but ChatPage has no UI for users to set/view it.

m-2: Onboarding doesn't trigger actual download/load (FR-044)

OnboardingPage is informational only — no interactive model download or loading.

m-3: GPU detection Windows-only (NFR-012)

detect_gpu uses wmic (Windows). macOS/Linux return (None, None).

m-4: No OOM guard before load_model (NFR-004)

CanItRun shows warnings on detail page. ModelRunPanel doesn't check before loading.

m-5: Context overflow auto-truncates silently (EC-010)

Spec says "warn user and offer to summarize or truncate." Implementation silently removes oldest messages.

m-6: No confirm dialog when loading second model

inference.rs:59-63 silently kills running model. Spec says "ask to confirm unloading."
