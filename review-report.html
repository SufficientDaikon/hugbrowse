📝 Recommendations (Priority Order)

🔴 Critical (Must Fix)

  1. FR-032 — Auto-start API server: Persist last-loaded model path and auto-load on startup if API was enabled. Add a flag in Tauri Store.
  2. FR-020 / EC-003 — Sidecar binary verification: Compute SHA-256 of the bundled llama-server binary on first launch. Store expected hash in a resource file.
  3. FR-043 — Tool Call badge: Add a ToolCallBadge component to ChatMessage.tsx that renders when message.role === "tool".

🟠 Major (Should Fix)

  1. FR-034 — PDF/DOCX support: Add pdfjs-dist for PDF text extraction and mammoth for DOCX. Extend readFileAsText() with MIME-type dispatch.
  2. FR-035 — Embedding-based retrieval: Use llama-server's /v1/embeddings endpoint for true vector similarity. Replace BM25 scoring with cosine similarity on embedding vectors.
  3. FR-041 — MCP chat integration: Parse assistant messages for tool-call JSON blocks in the SSE handler. Dispatch to mcpClient.callTool() and inject result as a tool message.
  4. FR-026 — System prompt UI: Add a collapsible "System Prompt" textarea in the chat header or session sidebar.
  5. FR-046 — Complete tray menu: Add "Quick Chat" (opens chat route) and "Stop [Model]" (calls unload) items to the tray menu.
  6. EC-007 — Multi-GPU: Enumerate GPUs via nvidia-smi and expose a GPU selector dropdown in ModelRunPanel.

🟡 Minor (Nice to Have)

  1. FR-022: Add highlight.js or shiki for syntax-highlighted code blocks.
  2. FR-037: Persist RAG chunk store to disk (IndexedDB or a local JSON file) so embeddings survive page reloads.
  3. NFR-009: Reduce health poll failure threshold to 1 (2s detection) and add a "Reload Model" button in the error state UI.
  4. FR-047/048: Wire up the Tauri updater plugin with check-on-launch + notification toast + one-click apply UI.
  5. NFR-012: Add macOS GPU detection (via system_profiler) and Linux GPU detection (via lspci).
