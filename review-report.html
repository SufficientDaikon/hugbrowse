🔴 Critical (3)

CRITICAL   F-001: HF Token Stored in Plaintext localStorage

The Hugging Face API token is stored via Zustand's localStorage persistence rather than Tauri's encrypted plugin store. Any process on the user's machine can read it. This violates NFR-007 and the guard rail "No user credentials (HF token) may be written to disk in plaintext outside the existing Tauri store."

Affects: FR-005, NFR-007, SC-006 · File: src/stores/settings.ts:65

Phase 6 RAG is only a store stub — no chunking, embedding, retrieval, or document attachment UI. All 5 RAG functional requirements (FR-034 to FR-038) are missing or stubs only. SC-009 cannot be verified.

7. Verdict & Recommendations

📊 VERDICT: NEEDS REVISION (58.9%)

The core P1 pipeline (Phases 1–3) is solid at 92% compliance — Tauri build, download manager, and llama-server sidecar are well-implemented. Phase 4 (Chat) is functional but has notable gaps (no syntax highlighting, no tok/s metrics, no system prompt UI). Phase 5 (API) leverages llama-server's native endpoints effectively. P2/P3 features (RAG, MCP, tray, auto-update) are either stubs or entirely missing, dragging the overall score below 60%.

Priority Recommendations

  • CRITICAL — Migrate HF token to Tauri encrypted store: Replace Zustand localStorage with tauri-plugin-store for the HF token. This is a security requirement (NFR-007) and a spec guard rail violation.
  • HIGH — Add syntax highlighting: Install rehype-highlight or shiki and integrate into ChatMessage.tsx CodeBlock component. Quick win for FR-022.
  • HIGH — Add tok/s and context usage display: Parse llama-server's SSE usage field in the streaming response to show tokens/second and context fill percentage. Addresses FR-027.
  • HIGH — System prompt UI: Add a small settings panel in the chat sidebar for editing the session's system prompt. Backend is already wired.
  • MEDIUM — Reduce crash detection latency: Change health poller from 10s/3-fail to 2s/2-fail to meet NFR-009's 2-second requirement.
  • MEDIUM — Cross-platform GPU detection: Add macOS (system_profiler) and Linux (lspci/nvidia-smi) GPU detection to lib.rs:72.
  • MEDIUM — Implement Phase 6 (RAG): Add document upload UI, chunking via token splitter, embedding via llama-server /v1/embeddings, vector storage, and retrieval injection into chat context.
  • LOW — System tray (Phase 8): Add tauri-plugin-tray for minimize-to-tray behavior. Lower priority than core feature gaps.
  • LOW — Port collision detection: Before spawning llama-server, attempt a TCP bind on the port. If it fails, suggest port + 1.
